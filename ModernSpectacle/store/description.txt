ModernSpectacle 是一个 macOS 菜单栏窗口管理工具。按一个键，它根据你此刻在做的事，把所有窗口排成人机交互研究证明更高效的布局；也保留经典 Spectacle 的全部快捷键（半屏、四角、三分之一、跨屏）。适合同时开着很多窗口、用大屏或超宽屏、习惯用键盘的人。

为什么这样排：每条规则背后都有研究
• 主窗口放在视线中央。Bi 与 Balakrishnan（CHI 2009）在真实办公中记录了一周大屏使用：81% 的鼠标操作发生在屏幕中央区域，用户把中间当作主任务的「焦点区」，外围放邮件、聊天这类只需留意的应用，并且越相关的窗口放得越近。ModernSpectacle 的超宽屏默认布局就是这样：主窗口居中，任务需要的紧挨在一侧，只需留意的放在另一侧。
• 一键把外围窗口换到中央。同一项研究发现，最常见的操作是把外围应用拖到中间用一下再拖回去，论文直接建议提供「一键切到焦点区」。这就是 ⌃⌥⌘↩「移到主位」。
• 当前任务的窗口平铺，不重叠。Kandogan 与 Shneiderman 的 Elastic Windows 实验（1997）显示：同时用 6 到 12 个窗口时，分组平铺比互相重叠的窗口明显更快，部分任务快到 10 倍。
• 其余窗口叠在边上，露出一条边。Hutchings 与 Stasko（GI 2004）访谈发现，一半用户会刻意让被遮住的窗口露出一角，方便一下点回来，也起提醒作用。不属于当前任务的窗口进右侧堆叠区，标题栏错开露出。
• 不乱动你的布局。界面元素一重排，用户就得重新记位置（Scarr、Cockburn、Gutwin 的空间记忆综述）。所以再次排列时沿用上次的模版，窗口留在原来的格子，新窗口只填空位或进堆叠。
• AI 只决定「谁放哪」，尺寸由本地算法保证。DuoZone（2025）的 16 人对照实验里，「AI 选格子、本地算尺寸」的方式让布局任务快了 34.5%、认知负荷显著降低；同一研究也发现，让 AI 直接给尺寸，结果近乎随机。ModernSpectacle 采用同样的分工，并设了可读性下限：浏览器至少 640 点宽，不会被挤成一条。
• 能保存的布局。DuoZone 和 2026 年的混合现实摆放研究都发现，用户希望把常用布局存成预设、一键恢复。⌃⌥⌘1…9 就是这个功能。

主要功能
• 智能排列 ⌃⌥⌘A：Claude 根据你最近在用什么、焦点在哪，为每块屏幕挑选布局模版、把窗口分到格子里。超宽屏、普通显示器、笔记本屏各有一套模版。窗口变化时会提前算好方案，按下即排
• 移到主位 ⌃⌥⌘↩：把当前窗口换到中央主位，原来的主窗口退到它腾出的位置，本地完成，不调模型
• 保存布局：菜单里「保存布局…」给当前排列起名，⌃⌥⌘1…9 一键恢复。按应用和窗口标题找回窗口，跨屏也会移回去。不需要 API Key
• 学习你的习惯：排完你再挪动，它会记住；你手动把一个 App 的几个窗口铺开，它会主动问要不要把剩下的也铺上
• 经典快捷键：⌥⌘←/→/↑/↓ 半屏，⌃⌘←/→、⌃⇧⌘←/→ 四角，⌥⌘C 居中，⌥⌘F 最大化，⌃⌥←/→ 三分之一，⌃⌥⌘←/→ 跨屏，⌃⌥⇧←/→ 放大缩小，⌥⌘Z / ⌥⇧⌘Z 撤销重做
• 中英双语界面，默认跟随系统，可在设置里切换
• 新版本提示：每天检查一次本商店，有新版本时提示并提供下载链接，可在设置里关闭

系统要求
macOS 14 或更高版本，支持 Apple Silicon 和 Intel 芯片。智能排列需要自备 Claude API Key。

开始使用
1. 打开 dmg，把 ModernSpectacle 拖进「应用程序」文件夹，然后打开它。
2. 第一次使用时，在「系统设置 → 隐私与安全性 → 辅助功能」里打开 ModernSpectacle。移动其他应用的窗口需要这个权限。
3. 想用智能排列：菜单栏图标 → 设置，粘贴 Claude API Key 并保存。手动快捷键和保存的布局不需要 Key。

已知限制
• 快捷键暂时不能自定义。
• 智能排列会把窗口标题和 App 名发给 Claude（仅在你填了 API Key 时）。
• 新版本需要从提示里的链接下载安装，不会自动更新。
• 不会导入原版 Spectacle 的设置。
