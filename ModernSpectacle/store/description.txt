ModernSpectacle 是一个 macOS 菜单栏小工具，用键盘快捷键把当前窗口移到屏幕的一半、四分之一、三分之一，或者居中、最大化，不用拿鼠标拖。它是经典窗口管理工具 Spectacle 的 Swift 重写版，适合习惯用键盘、经常并排看多个窗口的人。

主要功能
• 智能排列 ⌃⌥⌘A：一键按当前任务把窗口分组平铺。编程工具一边、浏览器一边、Finder 层叠在角落；每块屏幕各自排列，窗口不会跨屏
• 学习你的习惯：排完你再挪动，它会记住；你手动把一个 App 的几个窗口铺开，它会主动问要不要把剩下的也铺上
• 智能排列由 Claude（claude-haiku-5-5）驱动：在设置里填自己的 API Key，存在钥匙串里。不填 Key 时智能功能关闭，其他手动快捷键照常可用，且完全不联网
• 半屏：⌥⌘← 左半屏，⌥⌘→ 右半屏，⌥⌘↑ 上半屏，⌥⌘↓ 下半屏
• 四角：⌃⌘← 左上，⌃⌘→ 右上，⌃⇧⌘← 左下，⌃⇧⌘→ 右下
• 居中 ⌥⌘C，最大化 ⌥⌘F；⌃⌥←/→ 在左中右三分之一之间切换
• 多显示器：⌃⌥⌘← / ⌃⌥⌘→ 把窗口移到上一个 / 下一个屏幕
• 放大 ⌃⌥⇧→、缩小 ⌃⌥⇧←，撤销 ⌥⌘Z、重做 ⌥⇧⌘Z
• 常驻菜单栏：也能直接点菜单执行操作，或临时停用全部快捷键；可设置开机自动启动；不联网

系统要求
macOS 14 或更高版本，支持 Apple Silicon 和 Intel 芯片。

开始使用
1. 打开 dmg，把 ModernSpectacle 拖进「应用程序」文件夹，然后打开它。
2. 第一次运行时，在「系统设置 → 隐私与安全性 → 辅助功能」里允许 ModernSpectacle。移动其他应用的窗口需要这个权限。
3. 菜单栏会出现它的图标，所有快捷键都列在菜单和设置里。

已知限制
• 快捷键暂时不能自定义，只能用上面的默认组合。
• 智能排列的窗口标题和 App 名会发给 Claude（仅在你填了 API Key 时）。
• 没有自动更新，新版本需要回到这里下载。
• 不会导入原版 Spectacle 的设置。
